# Nest savings planner

A preliminary React + TypeScript savings-goal dashboard built with Vite. The preview includes sample savings goals, a goal creation form, progress summaries, goal details, and a quick way to add contributions.

Goal data is held in app state for this prototype and resets when the page is reloaded. There is no account system, backend, or financial account connection.

## Run locally

```sh
npm install
npm run dev
```

## Validate

```sh
npm run build
npm run lint
```
